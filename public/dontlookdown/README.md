# 점프점프 (Don't Look Down) 에셋

## platforms 폴더 (1.webp ~ 10.webp)

- **경로**: `public/dontlookdown/platforms/`
- **크기**: 자유. 이미지 크기는 발판 박스(충돌 크기)에 **영향을 주지 않습니다.**
  발판 박스는 맵 생성 값(폭 45~150px)이고, 이미지는 그 폭에 맞춰 비율을 유지해 그립니다.
  윗면이 착지면이며, 남는 높이는 발판 아래로 늘어뜨립니다(블록·기둥·버섯처럼 세로가 긴 그림에 유리).
- **번호별 용도** (`lib/game/dontlookdown.ts`의 `pickPlatformImageId`):

| 번호 | 그림 | 쓰이는 발판 |
| --- | --- | --- |
| 1 | 나무 판자 | 일반 |
| 2 | 얼음 | 얼음(미끄러움) 전용 |
| 3 | 돌 | 일반, 가시 발판 바탕 |
| 4 | 구름 | 사라지는 발판 전용 |
| 5 | 잔디 | 일반, 시작·정상 발판 |
| 6 | 이끼 벽돌 | 일반, 체크포인트 |
| 7 | 돌 블록 | 좁은 발판(한 칸) |
| 8 | 버섯 | 좁은 발판(한 칸) |
| 9 | 나무 상자 | 움직이는 발판 전용 |
| 10 | 돌 기둥 | 좁은 발판(한 칸) |

이미지가 없거나 로드 실패 시 해당 발판은 기본 색상 박스로 표시됩니다.

## props 폴더 (선택)

- **경로**: `public/dontlookdown/props/`
- 파일이 있으면 그림을 쓰고, 없으면 코드로 그립니다(깃발·삼각 가시).
- 배경은 투명(webp 알파)으로.

| 파일 | 용도 | 권장 비율 |
| --- | --- | --- |
| `checkpoint_flag.webp` | 체크포인트 발판 오른쪽 위에 서는 깃발 | 세로형, 약 1:1.5 (예 200×300) |
| `peak_flag.webp` | 정상 발판 위 깃발·트로피 | 세로형, 약 1:1.2 (예 250×300) |
| `spikes.webp` | 가시 발판 윗면에 가로로 반복되는 가시 띠 | 가로형, 약 4:1 (예 400×100), 좌우 이어붙여도 자연스럽게 |

## bg 폴더 (선택)

- **경로**: `public/dontlookdown/bg/`
- 파일이 있으면 그림을 쓰고, 없으면 지금처럼 코드로 그립니다(삼각 산 실루엣, 회색 절벽 그라데이션).
- 하늘 그라데이션·구름·별은 코드가 그리므로 이 그림들은 **배경 투명**으로.

| 파일 | 용도 | 권장 |
| --- | --- | --- |
| `mountains.webp` | 화면 아래쪽 먼 산 띠. 가로로 이어붙여 반복되고, 올라갈수록 아래로 가라앉음 | 가로형 약 3:1 (예 1500×500), 좌우 끝이 이어지게 |
| `cliff.webp` | 양옆 절벽 벽. 세로로 이어붙여 반복, 오른쪽은 좌우 반전 | 세로형 약 1:3 (예 300×900), 위아래 끝이 이어지게, 왼쪽 벽 기준으로 그리기 |

## powerup 폴더

- **경로**: `public/dontlookdown/powerup/`
- **파일명**: `PowerUpType`과 동일 (`shield.webp`, `rocket.webp`, `energy.webp`, `double_points.webp`, `ghost.webp`)
- 맵에 떨어진 파워업(34px)·우측 인벤토리 UI에 사용됩니다. 정사각형 권장.
- 로드 실패 시 이모지로 폴백됩니다.

## 화면 크기(줌)

월드 1px이 화면 `WORLD.VIEW_SCALE`(0.75) px로 보입니다. 기기·화면 비율이 달라도 발판·캐릭터의 보이는 크기는 같고,
큰 화면은 맵을 더 넓게 봅니다. 요소를 더 작게 보이게 하려면 이 값을 줄이면 됩니다.
