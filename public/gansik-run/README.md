# 간식런 스프라이트

이 폴더에 파일을 넣기만 하면 게임이 자동으로 이미지를 쓴다. 코드 수정 없음.
파일이 없으면 캔버스 도형으로 그린다(지금의 기본 그림).

|---|---|---|---|

지금은 모든 칸이 채워져 있다. 바꾸고 싶은 것만 새로 넣으면 된다.

고양이는 강아지와 달리 다리를 번갈아 딛는 게 아니라 몸을 폈다 웅크렸다 하는 바운드 주법이다.
그래서 웅크림 프레임은 발이 공통 박스 바닥에서 317px(화면에서 약 47px) 위에 있고, 그만큼 몸이 떠오른다.

**도로는 밝기 25~45(거의 검정)다.** 그 위에 올라가는 그림(강아지·고양이)은 밝은 부분이 있어야 형태가 읽힌다.
강아지는 흰 꼬리·가슴·발이 그 역할을 한다. 어두운 색 한 가지로만 칠하면 아스팔트에 묻힌다.

### 달리기 애니메이션

`dog` → `dog-2` → `dog-3` → `dog-4` 순으로 있는 것만 돌려 쓴다(타워디펜스 몬스터와 같은 방식).
고양이도 `cat` → `cat-2` → `cat-3` → `cat-4`로 똑같이 동작한다 (쫓아오는 쪽이라 한 걸음 0.33초로 조금 빠르다).
장수와 무관하게 한 걸음이 늘 0.4초이므로, 2장만 넣어도 속도감은 같다.
프레임이 2장 이상이면 코드가 넣는 흔들림(위아래·좌우 기울기)은 40%로 줄어든다 — 그림이 이미 움직이기 때문.

**프레임을 다시 그릴 때 가장 중요한 것**: 캔버스 크기와 몸통·머리 위치가 네 장 모두 똑같아야 한다.
다리와 꼬리만 움직이고 나머지는 고정. 몸이 조금만 어긋나도 달리는 게 아니라 떨리는 걸로 보인다.

그리고 **투명 여백은 장마다 따로 잘라내면 안 된다.** 네 장의 바운딩 박스를 합친 하나의 박스로 같이 잘라야 한다.
게임이 그림의 맨 아래를 바닥선에 붙이기 때문에, 도약 프레임처럼 발이 위에 있는 장을 따로 자르면
그 발이 바닥에 붙어버려서 몸이 가라앉는다. (지금 네 장은 x71 y7에서 825×1529로 함께 잘라 맞춰 놓았다.)

**세로÷가로 상한이 있다.** 이보다 세로로 길면 높이에 맞춰 가로를 줄여 그리므로 홀쭉해 보인다.
`dog*` 1.95 · `cat` 2.0 · `obstacle` 1.28 · `obstacle-low` 0.81 · `obstacle-high` 1.35 · `box` 1.55 (`bone`은 제한 없음)

## 배경 (`bg/` 폴더)

`public/gansik-run/bg/`에 넣으면 쓰고, 없으면 지금처럼 코드로 그린다. 점프점프 `dontlookdown/bg/`와 같은 방식이다.

| 파일명 | 용도 | 화면에서 | 세로÷가로 |
|---|---|---|---|
| `bg/sky.png` | 하늘 바탕 (그라데이션만) | 화면 위 28%에 맞춰 **늘려서** 그림 | 3:1 권장 |
| `bg/skyline.png` | 지평선 실루엣 (산·도시 등) | 높이 화면의 20%, 화면 폭에 맞춰 **한 번만** 늘려 그림 | 3:1 권장 |
| `bg/tree.png` `bg/tree-2` | 길가 나무 (흔함). `bg/tree-3`을 넣으면 세 종류가 된다 | 차선 폭의 40% | 2.26 이하 |
| `bg/prop.png` `bg/prop-2` `bg/prop-3` | 길가 소품 — 가로등·표지판·덤불 (다섯 자리에 한 번) | 〃 | 〃 |

- `tree*`·`prop*`는 도로 바깥 가장자리에 **맨 아래가 땅에 닿게** 세운다. 여러 장 넣으면 번갈아 선다.
- **비대칭 그림(가로등·표지판)은 튀어나온 부분이 왼쪽으로 가게 그려 둘 것.**
  도로 왼편에 세울 때는 코드가 좌우를 뒤집으므로, 이 규칙을 지키면 램프·간판이 항상 도로 쪽을 향한다.
  반대로 그려 왔으면 넣기 전에 좌우 반전해서 저장한다.
- **별은 언제나 코드가 그린다**(`drawStars`). 깜빡이는 맛이 살아 있어야 해서 그림으로 대체하지 않는다.
  그러니 `sky.png`에는 별을 넣지 말 것. 넣으면 코드가 그린 별과 겹쳐서 두 겹이 된다.
- `sky`·`skyline` 둘 다 **화면에 맞춰 늘려서** 그린다. 타일링하지 않으므로 좌우 끝이 이어질 필요는 없다.
  대신 늘어나도 괜찮은 그림이어야 한다 — 세로 그라데이션과 실루엣은 괜찮지만,
  **달·구름·건물처럼 형태가 뚜렷한 것은 넣지 말 것**(기기마다 하늘 칸 비율이 가로 6.5:1~세로 1.8:1로 달라서 찌그러진다).
  `skyline`을 타일로 이어 붙였더니 눈 덮인 봉우리가 한 화면에 네 번 나와 반복이 그대로 보였다.
- 도로는 원근 사다리꼴이라 이미지로 못 바꾼다. 코드로 그린다.

## 규격

- **PNG, 투명 배경, 512×512** (정사각형 캔버스 안에 그림을 채우되 여백은 최소로).
  `obstacle-low`, `bone`처럼 납작한 것은 512×256 등 직사각형이어도 된다. 비율 그대로 그려진다.
- **바닥선 기준**: 그림의 맨 아래가 땅에 닿는 위치다. 아래 여백을 두지 말 것 (그림자는 게임이 그린다).
- 스타일: `public/title/gansik-run.webp`의 픽셀아트 강아지(검흰 보더콜리 + 빨간 두건)와 같은 톤.
- SVG로 감싸지 말고 PNG로. (SVG 감싸기는 용량만 33% 커지고 최적화가 안 됨)

## 넣은 뒤

```bash
node scripts/optimize-game-assets.mjs gansik-run
```

PNG를 512px webp로 바꾼다. 원본은 `raw-assets/gansik-run-original/`에 백업된다.
게임은 `.webp`를 먼저 찾고 없으면 `.png`를 쓰므로, 변환을 안 해도 동작은 한다.
