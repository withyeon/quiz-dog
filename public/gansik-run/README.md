# 간식런 스프라이트

이 폴더에 파일을 넣기만 하면 게임이 자동으로 이미지를 쓴다. 코드 수정 없음.
파일이 없으면 캔버스 도형으로 그린다(지금의 기본 그림).

## 파일 목록

| 파일명 | 용도 | 권장 시점 | 화면에서 크기 |
|---|---|---|---|
| `dog.png` | 플레이어 강아지, 달리는 모습 | **뒷모습 또는 3/4 뒷모습** (카메라가 강아지 뒤에 있음) | 차선 폭의 72% |
| `dog-jump.png` | 점프 중 (선택) | 없으면 `dog`를 위로 띄움 | 〃 |
| `dog-slide.png` | 슬라이드 중 (선택) | 없으면 `dog`를 납작하게 | 〃 |
| `cat.png` | 뒤에서 쫓아오는 고양이 | 뒷모습 (강아지를 향해 달림), 눈은 안 보여도 됨 | 차선 폭의 80% |
| `obstacle.png` | 일반 장애물 (차선 바꿔 피함) | 바리케이드·공사 표지 등 "막혀 있다"가 한눈에 | 차선 폭의 86% |
| `obstacle-low.png` | 바닥 장애물 (점프로 넘음) | 통나무·낮은 울타리. **납작하게** (높이 ≈ 폭의 1/3) | 차선 폭의 86% |
| `obstacle-high.png` | 공중 장애물 (슬라이드로 지나감) | 가로 막대·간판. **아래가 비어 있게** (기둥 두 개 + 위쪽 막대) | 차선 폭의 96% |
| `bone.png` | 뼈다귀 (+1) | 이미 있음 (`bone.webp`, 강아지 대소동 것 재사용) | 차선 폭의 44% |
| `bone-gold.png` | 황금 뼈다귀 (+10) | 이미 있음 (`bone-gold.webp`, 자동 생성) | 〃 |
| `box.png` | 아이템 박스 | 이미 있음 (`box.webp`, 강아지 대소동 랜덤박스 재사용) | 차선 폭의 58% |

바꾸고 싶은 것만 넣으면 된다. `dog`, `cat`, `obstacle*` 5개가 지금 비어 있다.

## 규격

- **PNG, 투명 배경, 512×512** (정사각형 캔버스 안에 그림을 채우되 여백은 최소로).
  `obstacle-low`, `bone`처럼 납작한 것은 512×256 등 직사각형이어도 된다. 비율 그대로 그려진다.
- **바닥선 기준**: 그림의 맨 아래가 땅에 닿는 위치다. 아래 여백을 두지 말 것 (그림자는 게임이 그린다).
- 스타일: `public/title/gansik-run.webp`의 픽셀아트 강아지(검흰 보더콜리 + 빨간 두건)와 같은 톤.
- SVG로 감싸지 말고 PNG로. (SVG 감싸기는 용량만 33% 커지고 최적화가 안 됨)

## 넣은 뒤

```bash
node scripts/optimize-game-assets.mjs gansik-run
```

PNG를 512px webp로 바꾼다. 원본은 `raw-assets/gansik-run-original/`에 백업된다.
게임은 `.webp`를 먼저 찾고 없으면 `.png`를 쓰므로, 변환을 안 해도 동작은 한다.
