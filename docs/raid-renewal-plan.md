# 황제 펭귄을 막아라! 리뉴얼 계획서

## 목표

"정답 → 체력 바가 줄어드는 화면"에 머물러 있는 레이드를, 반 전체가 **한 파티로 보스와 싸우는 느낌**이 드는 협동 퀘스트로 바꾼다. 원칙은 그대로 지킨다.

- 오답에는 벌이 없다. 누가 못 맞혔는지는 어디에도 나오지 않는다(익명 게이지, 기여만 표시).
- 보스 상태는 서버에 따로 두지 않는다. 모든 화면이 players 행과 `room.started_at` 시간표만으로 같은 상태를 계산한다.
- SQL 마이그레이션 없이 간다. 새 카운터는 이미 원자 증분 화이트리스트에 있는 `revival_streak`, `position` 을 쓴다.

## 현재 문제 (미리보기 `/dev/raid-preview` 로 확인)

- 폰에서 상단 헤더가 화면의 30%를 차지한다. HUD 라벨이 줄바꿈되고("내 데미 지") 퀴즈가 아래로 밀린다.
- 보스 무대: 왕좌의 방 배경이 복잡해 펭귄이 묻힌다. 펭귄이 작고(폰 112px), 타격 숫자가 작고 흐리다.
- 체력 바가 밋밋하다. 페이즈 표시, 깎이는 잔상, 방패 구간 표시가 없다.
- 보스가 아무것도 하지 않는다. "집중 공격"은 시간이 되면 저절로 오는 버프라 반이 함께 해낼 목표가 아니다.
- 반 친구들의 존재감이 없다("20명이 함께" 한 줄뿐). 선생님 화면은 일반 패널 나열이다.
- 보스 등장·처치·승리 연출이 약하다. 결과 화면은 내 숫자만 보여 준다.

## 참고한 협동 퀘스트 (조사 요약)

| 출처 | 가져온 것 |
|---|---|
| 크레이지 아케이드 몬스터 모드 (보스: 대왕문어·**황제펭귄**·황제물개) | 보스 등장 경고 카드, 물풍선 구출처럼 "벌 대신 동료가 돕는" 구조 |
| 메이플스토리 파티퀘스트(커닝 PQ 쿠폰 할당), 핑크빈·혼테일 | 단계(페이즈) 전환, 한 줄 HP 위의 페이즈 마커, "모두가 조금씩 기여해야 열리는 문" |
| 로스트아크 무력화 / WoW 차단·보스 타임라인 / 몬스터헌터 다운 | **예고 공격을 여럿이 끊으면 보스 기절 → 딜 타임** |
| 포켓몬GO 레이드 | 로비의 파티 구성 표시, 인원 기반 HP, 보상 카테고리 분리(내 기여·팀 기여) |
| 스플래툰 연어런 | 소프트 실패: 못 잡아도 "얼마나 막았는지"를 성과로 인정 |
| 오버쿡드·Clash 클랜게임 | 팀 별 등급, 최소 참여만으로 모두가 받는 보상 |
| Gimkit/Kahoot 팀 모드 | 큰 인원에서 개인 숫자 대신 묶음 표시, 순위 대신 기여 |

반면교사: Classcraft처럼 "한 명이 못 하면 팀이 피해"는 우리 원칙과 정면 충돌 → 쓰지 않는다.

## 바뀌는 규칙

### 1. 집중 공격 → 펭귄의 필살기 (예고 · 끊기 · 기절)

- 시작 45초 뒤부터 80초마다 펭귄이 20초 동안 필살기를 모은다(보스별 이름: 눈덩이 폭격·얼음 창 돌진·눈보라 호령·절대영도 브레스).
- 예고 중 **서로 다른 친구**가 반의 40% 이상 한 번씩 맞히면 끊긴다. 오로라 마법사는 2칸.
- 끊긴 순간부터 예고 끝 + 15초까지 **기절: 데미지 2배**. 빨리 끊을수록 기절이 길다.
- 못 끊으면 4초 동안 눈보라 연출만 지나간다. 점수·체력 손해 없음.
- 저장: `revival_streak` = 마지막으로 기여한 주기 번호+1, `position` = 끊기 기여 횟수(칭호용). 시작 때 0으로 초기화.

### 2. 황제 펭귄 분노 (연출)

마지막 황제가 체력 25% 아래로 떨어지면 붉은 오라·배경 톤 변화·배너. 규칙 변화는 없다.

### 3. 결과: 팀 별 + 모두에게 칭호

- 팀 별: 전부 처치 ★★★, 60% 이상 ★★, 25% 이상 ★. 못 잡아도 "펭귄 군단 N% 저지!"로 보여 준다.
- 칭호: 최강의 일격 · 명중왕 · 필살기 저지왕(공동 1등 모두) + 역할 칭호. 한 번도 못 맞힌 친구도 "함께한 용사".

## 화면 리뉴얼

| 영역 | 내용 |
|---|---|
| 학생 폰 레이아웃 | 큰 헤더를 얇은 HUD 한 줄로. 보스 무대를 키우고 퀴즈가 한 화면에 들어오게 |
| 보스 무대 | 보스별 배경(병사: 성문 앞마당 / 황제: 왕좌의 방), 스포트라이트·그림자, 보스 크기 확대 |
| 체력 바 | 75/50/25% 마커, 깎이는 흰 잔상, 방패 구간 빗금, 보스 이름표(번호·최종 보스 배지) |
| 타격 숫자 | 외곽선 굵은 숫자, 역할색, 콤보·기절 때 크게. 많을 땐 "+N" 묶음 |
| 보스 등장 카드 | WARNING 띠 → 실루엣 → 이름·필살기 한 줄 (약 2초) |
| 필살기 UI | 예고 바(시간) + 끊기 게이지(익명 칸), 기절 별 연출, 눈보라 서리 오버레이 |
| 파티 띠 | 반 친구 아바타가 고정 순서로 줄지어 있고, 맞힐 때 잠깐 빛난다. 안 맞힌 표시는 없다 |
| 역할 선택 | 역할 카드 + 반 전체 구성 막대("수호자가 적어요: 방패가 느려질 수 있어요") |
| 선생님 화면 | 프로젝터용 큰 무대, 필살기/방패 패널, 파티 벽(아바타 그리드), 공격 속도 게이지 |
| 결과 | 승리 배경, 팀 별·처치 수·반 전체 데미지, 내 칭호 카드, 선생님 화면엔 칭호 격자 |
