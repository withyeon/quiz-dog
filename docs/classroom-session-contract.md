# 교실 세션 계약

퀴즈독은 교실에서 선생님이 호스트하고, 아이들이 참여하고, 아이들끼리 상호작용하는 멀티플레이 사이트다. 모든 게임 모드는 이 제품 계약을 지켜야 한다.

1. 선생님이 방 생명주기의 권한자다.
   - 선생님은 방 생성, 시작, 일시정지, 재개, 종료, 초기화를 제어한다.
   - 선생님이 종료하거나 선생님이 설정한 시간이 끝나면, 아이가 게임이나 퀴즈 중이어도 즉시 결과 화면으로 넘어가야 한다.
   - 학생 쪽 시간 종료 처리는 선생님 화면 이벤트를 놓쳤을 때의 백업일 뿐이며, 반드시 방의 `started_at`과 `duration_seconds`를 기준으로 한다.

2. 아이들은 선생님 방에 참여하고, 공통 생명주기를 조작하지 않는다.
   - 학생 클라이언트는 방 코드, `playerId`, 방 상태, 실시간 이벤트로 올바른 게임 화면에 들어간다.
   - 학생 화면은 튜토리얼, 게임, 결과를 볼 수 있지만 튜토리얼 조작과 게임 생명주기 조작은 선생님 전용이다.
   - 종료 상태는 `finished`와 `ended`이며, 새 입장은 둘 다 막아야 한다.

3. 아이들끼리의 상호작용은 로컬 화면에만 남으면 안 된다.
   - 한 아이의 행동이 다른 아이에게 영향을 주면 player 업데이트나 room runtime event로 공유되어야 한다.
   - 지속 상태 변경은 `player:patch`, 즉시 효과는 게임별 이벤트를 사용한다.
   - 현재 예시는 보물찾기 공격, 배틀 공격, 카페 아이템 공격, 좀비 타깃 패치, 간식런 효과, 강아지 대소동 플레이어 패치다.

4. 새 게임 모드는 공통 패턴을 우선 사용한다.
   - 학생 게임 페이지는 가능하면 `useGameBase`를 쓴다.
   - `useGameBase`를 못 쓰는 게임도 `game:finished`와 종료 `room:patch`를 구독하고, 학생을 결과 화면으로 보내고, 점수 상태를 저장하고, 선생님 제한 시간을 지켜야 한다.
   - 선생님 화면은 게임 종료 시 `room:patch`, `room:snapshot-hint`, `game:finished`를 방송해야 한다.

새 모드나 생명주기 변경을 배포하기 전에는 선생님 호스트 제어, 학생 참여, 학생 간 상호작용이 함께 유지되는지 반드시 확인한다.
